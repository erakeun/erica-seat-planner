# ERICA Seat Planner

한양대학교 ERICA 본관 2층 PRIME 컨퍼런스홀 전용 좌석배치 제작기입니다. V1 저장 데이터와 좌석 ID를 유지하면서 V2 명단·다기관 행사 기능을 제공합니다.

## 실행

별도 설치 없이 `dist/index.html`을 열거나 정적 웹 서버로 `dist` 폴더를 제공하면 됩니다.

## 좌석 Geometry

- 화면 상단 메인석 24석 (`MAIN-L-01` ~ `MAIN-L-24`, 기존 ID 유지)
- 화면 하단 메인석 24석 (`MAIN-R-01` ~ `MAIN-R-24`, 기존 ID 유지)
- 화면 왼쪽 중앙석 1석 (`HEAD-01`), 독립된 전용 대형 테이블 1개
- 화면 상단 수행원석 14석 (`STAFF-01` ~ `STAFF-14`), 2인용 테이블 7개
- 총 63석, 메인석·중앙석 모니터 49대

상·하단 메인석은 실제 가구 기준인 모니터 2대당 테이블 1개로 나누어 각각 12개 모듈로 표시합니다. `MAIN-L-12`와 `MAIN-R-12`는 좌석 배정 여부와 무관하게 `CENTER` 기준 좌석으로 표시됩니다. 이 가구 모듈과 중앙석 표시는 렌더링 정보이며 기존 좌석 ID·저장 스키마·자동배치 정책을 변경하지 않습니다.

승인 기준 이미지에 맞춰 엠블럼 벽면은 왼쪽, 스크린은 오른쪽, 창가는 하단으로 표시됩니다. U자형 테이블은 오른쪽이 열려 있으며 상단은 중앙이 위로, 하단은 중앙이 아래로 휘어 중앙 간격이 가운데에서 넓어집니다. 상단 왼쪽에는 단차가 있는 복도와 서로 다른 벽면의 출입문 2개가 배치됩니다.

좌석 ID, 브라우저 저장 키(`erica-seat-planner:v1`), JSON 스키마 버전은 기존 V1과 호환됩니다.

## V2 운영 기능

- 상단 `참여기관` 관리에서 기관명, 역할, 표시순서, 기준 좌석을 등록하고 참석자와 연결
- UTF-8 BOM 예시 CSV, 업로드 후 편집 가능한 미리보기, 오류·정원·고정좌석 충돌 검증
- 기관 내 사용자 지정 숫자 순위와 실제 좌석 X좌표를 이용한 `좌석 자동배치(초안)`
- 고정 좌석 우선, `HEAD-01` 기본 제외 옵션, 수행원석 7테이블 × 2석 자동배치
- 적용 전에는 현재 배정을 건드리지 않고, 적용 시 전체 초안을 한 번의 Undo 작업으로 기록
- `명패 만들기`로 URL에 참석자 정보를 싣지 않는 창 간 메시지 방식의 명패제작기 연동

## 현장 실측 반영

- 상·하단 메인 장변 테이블 깊이: 각 800mm
- 수행원 대표 테이블 모듈 깊이: 800mm를 동일 모듈 7개에 적용
- 오른쪽 열린 끝의 상판 외곽과 스크린 쪽 벽 안쪽 면 사이: 1000mm
- 모델 단위: 1m = 100 화면 단위, x/y 동일 축척

상석 뒤 1800mm와 출입문 옆 2200mm는 사진에서 측정 끝점을 확정하기 어려워 참고값으로만 기록했습니다. 전체 방 크기·테이블 길이·곡률 반경·상석 연결부 깊이는 미실측이며 실제 시공 치수로 사용할 수 없습니다. 상세 기록은 `FIELD_MEASUREMENT_NOTES.md`를 참조하세요.

좌표는 사진과 도면에서 확인되는 상대적 공간 비례를 바탕으로 구성했으며 실제 건축 치수로 사용하면 안 됩니다.

## 배포

GitHub Pages 배포용 워크플로가 포함되어 있습니다. 저장소의 Pages Source를 `GitHub Actions`로 설정하면 `dist` 폴더가 배포됩니다.

## V2.1 안정성 패치

- 손상되거나 지원하지 않는 저장 데이터는 원본을 보존하고 자동저장을 중지합니다. JSON 내보내기로 원본을 내려받을 수 있습니다.
- JSON 가져오기와 새 배치는 직전 원본을 별도 키에 백업합니다. `교체 전 백업 JSON 내려받기`에서 다운로드 후 JSON 가져오기로 복구할 수 있습니다. 백업은 가장 최근 교체 1회이며 브라우저 데이터 삭제 시 함께 사라집니다.
- 다른 탭에서 저장한 변경은 오래된 탭이 덮어쓰지 않습니다. 안내가 나오면 백업 후 새로고침해 주세요.
- 고정석은 수동 이동·교환·배정 해제로 변경되지 않습니다. 참석자 수정에서 먼저 고정을 해제합니다.
- 자동배치는 기본적으로 기존 배정을 유지합니다. 재계산 옵션을 켜도 고정석·중앙석은 유지합니다. HEAD-01 신규 배정은 운영자가 참석자를 직접 선택합니다.
- 각 기관 기준석을 먼저 예약한 뒤 좌우로 확장합니다. 같은 기관의 고정 대표가 기준석을 차지한 경우에도 동료를 주변에 배정할 수 있습니다. 정원 부족·기준석 충돌·중복 순위는 적용을 막습니다.
- CSV에는 일반 배정좌석과 보조 그룹을 함께 내보냅니다. 완전한 행사 복원에는 JSON을 권장합니다. 스프레드시트 수식 시작 문자는 텍스트로 보호합니다.
- 명패 가져오기는 명패 창에서 확인해야 완료됩니다. 수신 창에서 이전 프로젝트를 백업합니다. 전송 실패 시 CSV 내보내기/명패 CSV 가져오기로 계속할 수 있습니다. 기관 로고는 명패 창에서 직접 지정합니다.

검증: `node --test tests/*.test.mjs`. 테스트에는 가상 데이터만 사용합니다. Geometry, 좌석 ID, V1 저장 키는 변경하지 않았습니다.
